# ✋ AI-FingerCounting

AI-FingerCounting is a real-time computer vision project that uses Python, OpenCV, and MediaPipe to detect hand landmarks and accurately count fingers through a webcam feed.

---

# 🚀 Features

* Real-time finger counting
* Hand tracking using AI
* Webcam integration
* Fast and accurate detection
* Simple and interactive UI

# 🎥 How It Works

* Captures webcam video
* Detects hand landmarks using MediaPipe
* Identifies raised fingers
* Displays real-time finger count on screen
